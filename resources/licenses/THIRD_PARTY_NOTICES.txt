4. Notes
--------

  Note 1 - Where a library is listed with more than one set of terms, the
  bundled license file records which terms apply to which parts. This file does
  not restate or interpret that allocation.

  Note 2 - The upstream sharp-libvips notice states: "Use of libraries under the
  terms of the LGPLv3 is via the 'any later version' clause of the LGPLv2 or
  LGPLv2.1." The license file reproduced for each of those libraries is the
  license text published by that library upstream, which is LGPL version 2 or
  2.1 with an "or later" clause. The LGPL version 3 and GPL version 3 texts are
  reproduced verbatim in bundled/libheif/COPYING.

  Note 3 - The upstream sharp-libvips notice lists cairo as being used under the
  Mozilla Public License 2.0. The COPYING file published by cairo 1.18.4 offers
  cairo under the LGPL version 2.1 or the Mozilla Public License 1.1, and does
  not mention MPL 2.0. All three cairo files are reproduced in bundled/cairo/.
  This discrepancy is recorded, not resolved. LEGAL REVIEW RECOMMENDED.

  Note 4 - libnsgif is not built as a separate library and has no entry in the
  versions.json shipped with the binary packages. It is vendored into libvips
  itself, under libvips/foreign/libnsgif. The license text in
  bundled/libnsgif/COPYING is the COPYING file from that directory at libvips
  tag v8.18.3, which is the exact libvips version shipped on both platforms.
  libnsgif carries no independent version number there, so the "Version" column
  above reads "vendored" rather than a release number.

  Note 5 - Nine libraries are built at a different version or commit for Windows
  x64 than for Linux x64 and macOS (expat, glib, libarchive, libffi, libheif,
  librsvg, libtiff, libultrahdr and pango). The license file published upstream
  at each Windows version was fetched and compared byte-for-byte against the
  license file published at the corresponding Linux version; all nine pairs are
  identical, so the single file referenced above covers every platform.

  Note 6 - Every license file referenced above was copied byte-for-byte from the
  npm package that this application redistributes, or from the library's own
  canonical source repository at the exact version or commit recorded in
  versions.json. No license text in this directory has been retyped, summarised
  or edited.


5. Location of the native libraries in installed packages
----------------------------------------------------------

  The sharp native addon and the prebuilt libvips shared libraries are shipped
  as ordinary files outside the application archive (app.asar), under:

    Linux    <install dir>/resources/app.asar.unpacked/node_modules/@img/
    Windows  <install dir>\resources\app.asar.unpacked\node_modules\@img\
    macOS    <app bundle>/Contents/Resources/app.asar.unpacked/node_modules/@img/

  Specifically:

    Linux    .../@img/sharp-libvips-linux-x64/lib/libvips-cpp.so.8.18.3
             .../@img/sharp-linux-x64/lib/sharp-linux-x64-0.35.3.node
    Windows  ...\@img\sharp-win32-x64\lib\libvips-42.dll
             ...\@img\sharp-win32-x64\lib\libvips-cpp-8.18.3.dll
             ...\@img\sharp-win32-x64\lib\sharp-win32-x64-0.35.3.node
    macOS    .../@img/sharp-libvips-darwin-<arch>/lib/libvips-cpp.8.18.3.dylib
             .../@img/sharp-darwin-<arch>/lib/sharp-darwin-<arch>-0.35.3.node

  These files are not compressed into or otherwise merged with app.asar, and
  they are not statically linked into the application executable.
